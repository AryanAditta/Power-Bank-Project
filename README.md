# Rechargeable Power Bank Circuit

**Portable charging-circuit project built around a lithium-ion battery, charger module and boost-converter stage.**

The project studies the basic architecture of a rechargeable power bank, including battery charging, voltage conversion and protection-oriented design considerations for portable device charging.

## Functional Blocks

- Rechargeable lithium-ion battery source.
- Battery-charging module.
- DC-DC boost conversion for device charging.
- Basic overcharge/battery-protection considerations.
- End-to-end documentation of the circuit concept and implementation.
